# Numerix

**A Python library for numerical analysis and mathematical visualization**

🚧 **Project Status: In Progress** 🚧  
This library is currently under active development. Features, structure, and APIs may change.

---

## Overview

**Numerix** is a Python library designed to:

- Implement classical numerical methods
- Visualize mathematical functions
- Display iterative steps of numerical algorithms
- Provide clear graphical insight into convergence behavior

The goal of this project is to combine **numerical computation** and **visual learning** into a reusable and extensible toolkit.

---

## Current Features

✔ Mathematical function plotting  
✔ Cartesian plane visualization  
✔ Multiple function graphing  
✔ Iteration visualization framework (in development)

---

## Planned Features

- Root-finding algorithms:
  - Bisection Method
  - Regula Falsi Method
  - Newton-Raphson Method
  - Secant Method

- Iteration visualization:
  - Interval shrinking
  - Midpoint tracking
  - Convergence highlighting

- Additional utilities:
  - Graph exporting
  - Custom styling
  - Error visualization
